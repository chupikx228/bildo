Приложение для отслеживания привычек — для людей с гибким, самостоятельно выстроенным днём: фрилансеров, студентов на удалёнке, тех, у кого нет чёткого 9-to-5 и кто заглядывает в привычки урывками между задачами, а не по расписанию. Ключевая эмоция — тихая уверенность в движении вперёд, без школьного «ты пропустил» тона.

Дизайн-система: фон #FAF7F2 (тёплый почти белый с лёгким бумажным подтоном — не кремово-terracotta), поверхность карточек #FFFFFF, основной текст #22201B, вторичный текст #8A8478, акцент — приглушённый горчично-жёлтый #D9A441 (не оранжевый и не неон — выбран из слова «гибкий», тепло без спешки и срочности), текст на акценте #22201B, разделители #ECE7DD, success #6B8F5C, error #C1615A.

Layout: доминанта верхнего экрана — не цветная карточка-герой, а крупная типографика прямо на фоне (число дней подряд, 70-80pt), ниже — плотная лента карточек, потому что пользователь листает урывками между задачами и должен считать статус одним взглядом, а не рассматривать простор.

Плотность — компактная: карточки 60-64px, отступы 8-10px.

Типографика — уверенная, слегка гротескная, без засечек, среднего контраста.

Экраны: 1) Сегодня — доминанта: число текущей серии крупным текстом вверху. 2) Привычки — доминанта: сама лента карточек с историей за неделю. 3) Новая привычка — доминанта: поле названия, остальные поля свёрнуты ниже и визуально тише.

Тон: короткий, дружелюбный, по делу. Кнопка сохранения — не «Сохранить», а «Готово, добавили». Пустое состояние: «Пока пусто — начни с одной привычки, не с десяти».
