# bildo — дизайн-система

Спецификация интерфейса: цвета, типографика, геометрия, компоненты, поведение и анимация.

Документ не привязан к конкретной кодовой базе, фреймворку или структуре файлов. Имена токенов и классов ниже — **условные роли**, не требование к именованию. Обязательны только значения, пропорции и поведение: реализация по этому документу должна выглядеть один в один.

Область: интерфейс продукта (лендинг + редактор). Содержимое превью мобильного приложения стилизуется данными самого приложения, а не этой системой — см. раздел 12.

---

## 0. Принципы

1. **Светлая, почти монохромная база.** Фон белый и очень светло-серый. Вес несут текст и тонкие линии, а не заливки.
2. **Волосяные линии вместо теней.** Границы 1px: `#EBEBEE` — разделители блоков, `#DEDEE3` — границы контролов. Тени мягкие, почти незаметные.
3. **Цвет — смысл, а не украшение.** Индиго = действие, выделение, AI. Зелёный = добавлено/успех. Оранжевый = изменено. Красный = удаление и выход. На элементах управления не бывает декоративного цвета.
4. **Чёрный — для главного действия в контенте, индиго — для главного действия в интерфейсе.**
5. **Тонирована ровно одна поверхность** — рабочая доска. Белые панели читаются как бумага над ней.
6. **Радиусы крупнее привычного:** контролы 9–11px, карточки 12–18px. Прямых углов нет нигде.
7. **Анимация только функциональная:** подтверждение действия, появление слоя, ожидание. Всё уважает `prefers-reduced-motion`.

### 2.2 Правила применения

- **Единый паттерн наведения** для всего интерактивного: фон `accent-wash`, граница `accent-line`, текст `accent-strong`. Так ведут себя кнопки, пункты меню, переключатели, строки списков.
- **Включённое состояние** = тот же паттерн + вес 600 + внутренняя тень `inset 0 1px 2px rgba(46,55,150,.08)`. Стиль не должен сбрасываться при наведении.
- **Выделение объекта** на рабочей области — только акцентный индиго, без вариантов.
- **Красный никогда не заливает элемент целиком** — только мягкий фон с тёмно-красным текстом.
- Новый цвет вводится, только если у него есть отдельный смысл. Оттенок ради оттенка — нет.

## 4. Геометрия

### 4.1 Радиусы

| Значение | Применение |
|---|---|
| 2px | точка-индикатор |
| 4–6px | мелкие контролы, поля свойств, образец цвета |
| 8px | имя документа, второстепенные кнопки |
| **9px** | **базовый радиус кнопок и полей ввода** |
| 10px | панель выравнивания, кнопки лендинга |
| 11px | поле и кнопки строки чата |
| 12px | карточка в списке |
| 14px | пузырь сообщения, карточка предложения, всплывающее меню |
| 16px | карточка ввода промпта |
| 18px | модальное окно интервью |
| 999px | чипы, бейджи, переключатели |
| 40 / 50px | экран / корпус в макете телефона |

### 4.2 Отступы

Шаг сетки **4px**. Рабочие значения: 4, 6, 8, 10, 12, 14, 16, 20, 28.

- Шапка: `0 14px`, между группами 12px, внутри группы 8px.
- Секция панели свойств: `14px 16px 16px`, снизу разделительная линия.
- Шапка панели свойств: `14px 16px 12px`.
- Лента сообщений: `14px 12px 16px`, между сообщениями 12px.
- Строка ввода чата: `10px`, между элементами 8px.

### 4.3 Высоты интерактивных элементов

| Элемент | Высота |
|---|---|
| Верхняя шапка | 56px (минимум) |
| Шапка колонки/панели | 48px |
| Кнопка | 32px (минимум); иконочная 30×30 |
| Имя документа в шапке | 30px |
| Кнопка выбора цвета | 30px |
| Числовые поля свойств | 28px |
| Строка «подпись — контрол» | 32px (минимум) |
| Поле, кнопка отправки и кнопка вложения в чате | 36px — **все три одинаковые** |
| Чип вложения | 26px |
| Переключатель | 30×18px, кнопка 14px, ход 12px |

### 4.4 Тени

```
sm: 0 1px 2px rgba(16,16,20,0.05)                                    /* кнопки, карточки */
md: 0 4px 14px rgba(16,16,20,0.07), 0 1px 2px rgba(16,16,20,0.05)    /* поднятые панели */
lg: 0 18px 48px rgba(16,16,20,0.14), 0 2px 6px rgba(16,16,20,0.06)   /* меню, оверлеи */
```

У акцентных кнопок тень цветная: `0 1px 2px rgba(46,55,150,.22), 0 6px 16px rgba(92,108,245,.22)`.

### 4.5 Скроллбары

Ширина и высота 8px, дорожка прозрачная. Ползунок `#D9D9E0`, радиус 4px, прозрачная рамка 2px с обрезкой по padding-box (создаёт визуальный зазор), при наведении `#C2C2CC`. Тонкий вариант там, где поддерживается нативно.

### 4.6 Фокус

Кольцо фокуса — **только для клавиатурной навигации**: обводка 2px акцентным цветом, отступ 2px, радиус 2px.

Фокус внутри поля ввода выглядит иначе: граница `#B9C0FA` + мягкое кольцо `0 0 0 3px rgba(92,108,245,.12)`.

## 5. Компоненты

### 5.1 Кнопка

Базовое состояние:

```
минимальная высота: 32px
раскладка: inline-flex, по центру обеих осей, зазор 6px
граница: 1px line-strong
радиус: 9px
внутренние отступы: 6px 11px
фон: #FFFFFF
текст: text-soft, 500 12px/1
тень: sm
переход: .16s ease для фона, границы, цвета, тени и трансформа
```

| Состояние | Оформление |
|---|---|
| Наведение | фон accent-wash, граница accent-line, текст text |
| Нажатие | `translateY(1px)`, тень снимается |
| Отключено | `opacity: .45`, курсор запрета, без тени |

**Варианты:**

| Вариант | Оформление |
|---|---|
| Главное действие | вертикальный градиент `#6B7BFF 0% → #5C6CF5 55% → #4A55C9 100%`, граница `#4A55C9`, белый текст, вес 600, цветная тень. Наведение: градиент `#7C8AFF → #5A69F2 → #4450C4`, тень усиливается до `0 8px 22px rgba(92,108,245,.3)` |
| Опасное / выход | фон danger-soft, граница `rgba(220,38,38,.3)`, текст `#B91C1C`, вес 600. Наведение: фон `rgba(220,38,38,.16)`, текст `#991B1B` |
| Тихое | прозрачные фон и граница, текст muted, без тени. Наведение: фон accent-wash, текст accent-strong |
| Иконочное | ширина 30px, внутренние отступы обнулены |
| Включено | фон accent-wash, граница accent-line, текст accent-strong, вес 600, `inset 0 1px 2px rgba(46,55,150,.08)`. **Не сбрасывается при наведении** |

Смысл варианта «опасное» — выход из режима превью не должен читаться как обычное действие.

### 5.2 Поля ввода

Два вида, различие осмысленное и обязательное:

**Поле в панели** (ввод текста, поиск): ширина 100%, граница 1px line-strong, радиус 9px, отступы `8px 10px`, фон белый, текст 400 13px/1.35, плейсхолдер faint.

**Поле свойства** (правка значения объекта): фон surface, граница 1px line-strong, радиус 6px, отступы `8px 10px`, размер 12px, без внешней обводки.

Белое = «введите что-то новое», серое = «поменяйте существующее значение».

### 5.3 Числовое поле со степпером

Значение с кнопками `−` и `+`, шаг 1, ограничение min/max.

```
контейнер: inline-flex, высота 28px, радиус 6px,
           граница 1px line-strong, фон surface, overflow: hidden
кнопки:    26×28px, без границ, прозрачный фон, символ 14px цветом muted
поле:      по центру, tabular-nums, нативные стрелки браузера скрыты
```

Степперы ставятся **только на дискретные величины** (радиус, отступ, координата). На непрерывных (прозрачность) — ползунок плюс ввод с клавиатуры, без кнопок.

### 5.4 Компактное числовое поле

Для координат и размеров (X, Y, W, H).

```
контейнер: высота 28px, радиус 6px, граница 1px line-strong, фон surface
лейбл:     ширина 18px, 9px/650, цвет subtle, по центру, не выделяется мышью
поле:      отделено вертикальной линией line-strong, отступы 0 8px,
           12px, tabular-nums, растягивается на остаток
```

Полю обязательно задавать возможность сжиматься ниже содержимого — иначе длинные значения обрезаются справа.

### 5.5 Выбор цвета

Кнопка-триггер: высота 30px, отступы `0 8px 0 4px`, радиус 6px, граница line-strong, фон surface. Слева квадрат-образец 18×18px, радиус 4px, обводка `rgba(16,16,20,0.16)`. Справа HEX-код: **`#101014`, вес 550, 11px, uppercase**. Серый текст для кода цвета не использовать — нечитаемо.

Строчный вариант: сетка `28px | остаток`, зазор 8px, высота от 34px, отступы `3px 8px 3px 3px`, радиус 9px, белый фон. Нативный инпут цвета внутри — 26×26px, радиус 5px, без границ.

Палитра: область насыщенности высотой ~140px с радиусом 8px и отступом снизу 8px, полоса оттенка 10px с радиусом 999px, курсор 14px с обводкой 2px.

### 5.6 Чип вложения

```
inline-flex, зазор 6px, максимальная ширина 220px, высота 26px
отступы: 0 7px 0 9px
радиус: 999px, граница 1px #E4E4EA, фон #F7F7F9, текст muted 11px
```

Имя файла обрезается многоточием, размер — второй строкой или после имени. Кнопка удаления полупрозрачная (`.5`), при наведении непрозрачная.

Вариант-индикатор режима: граница accent-line, фон accent-wash, текст accent-strong, вес 600.

### 5.7 Всплывающее меню

```
ширина 264px (в узких колонках 236px), внутренний отступ 6px
радиус 14px, граница 1px line-strong
фон rgba(255,255,255,.98) с размытием подложки 18px
тень lg
появление: 0.18s основной кривой
```

Пункт: отступы `9px 10px`, радиус 9px, 13px, текст text-soft, иконка слева акцентным цветом, наведение — фон accent-wash. Разделитель: линия 1px `#EBEBEE` с отступами `5px 8px`. Пункт-переключатель: заголовок и под ним пояснение 11px цветом subtle.

**Важно:** меню внутри колонок с обрезкой переполнения выносится в отдельный слой над всем интерфейсом с фиксированным позиционированием; координаты вычисляются от прямоугольника кнопки. Иначе меню будет обрезано колонкой или закрыто рабочей доской.

### 5.8 Переключатель

Дорожка 30×18px, радиус 999px, фон line-strong, внутренний отступ 2px. Кнопка 14×14px, белая, тень `0 1px 2px rgba(16,16,20,.2)`. Включено: дорожка акцентная, кнопка смещается на 12px, переход 0.16s основной кривой.

### 5.9 Карточка списка

Отступы 16px, радиус 12px, граница 1px `#E4E4EA`, белый фон, тень sm. Название весом 600, под ним дата 12px цветом subtle с отступом 4px. Деструктивное действие — текст danger на прозрачном фоне с нейтральной границей, радиус 8px, отступы `6px 10px`.

## 6. Раскладка редактора

Четыре колонки под общей шапкой:

```
┌─────────────────────────────────────────────────────────────┐
│ Шапка · 56px                                                │
├──────────┬─────────┬─────────────────────┬──────────────────┤
│ Колонка  │ Файлы   │ Рабочая доска       │ Панель свойств   │
│ ассистен-│ 0 или   │ занимает остаток    │ 252–300px        │
│ та 352px │ ~280px  │                     │                  │
└──────────┴─────────┴─────────────────────┴──────────────────┘
```

Ширины первой и второй колонок управляются извне (сворачивание ассистента, открытие файлов) через переменные ширины сетки. Панели **меняют ширину сетки, а не накладываются поверх доски** — макет никогда не перекрывается интерфейсом.

### Шапка

Высота от 56px, отступы `0 14px`, нижняя граница line, фон `rgba(255,255,255,0.86)` с размытием подложки `saturate(180%) blur(12px)`.

Элементы собираются в **группы** с зазором 8px внутри и 12px между группами; между группами — вертикальный разделитель 1×20px цветом line. Ритм читается только по расстоянию между группами, поэтому внутри группы элементы стоят плотнее.

Порядок: логотип → имя документа → статус сохранения │ файлы, код │ превью, поделиться, экспорт.

Имя документа — поле ввода 190×30px, прозрачные фон и граница, вес 600, 13px. Наведение — фон surface, фокус — белый фон и граница accent-line. Ведёт себя как имя документа: незаметно, пока к нему не потянулись.

Под шапкой — единственный декоративный элемент всего интерфейса: горизонтальная линия 2px, `opacity: .5`:

```
linear-gradient(90deg,
  #5C6CF5 0%, #A855F7 26%, rgba(255,141,92,.7) 48%, rgba(92,108,245,0) 76%)
```

### Рабочая доска

```
background:
  radial-gradient(150% 130% at -12% -30%,
    rgba(92,108,245,0.085) 0%, rgba(92,108,245,0.035) 42%, rgba(92,108,245,0) 100%),
  radial-gradient(110% 100% at 108% 115%,
    rgba(255,141,92,0.08) 0%, rgba(255,141,92,0) 100%),
  #F2F2F6;
```

Поверх — точечная текстура, не перехватывающая события: `radial-gradient(circle, rgba(16,16,20,0.05) 1px, transparent 1px)` с шагом 22×22px.

Градиенты заданы в процентах и доведены до 100% намеренно: заливка покрывает всю доску без видимой границы затухания при любом размере окна. При меньших значениях подсветка в углу читается как индикатор загрузки — это ошибка.

### Адаптив

| Ширина | Поведение |
|---|---|
| ≤ 1020px | панель свойств скрывается, колонка ассистента сжимается до 320px |
| ≤ 720px | остаётся только доска; колонки ассистента и файлов скрыты; шапка ужимается до `0 10px` с зазором 6px, второстепенные элементы шапки скрываются |

## 7. Колонка ассистента (чат)

Полновысотная колонка слева от доски. Ключевое решение: **диалог растёт по своей оси и физически не может перекрыть макет.** Всплывающие поверх доски окна чата запрещены.

Фон колонки: вертикальный градиент `rgba(92,108,245,0.06)` → прозрачный на протяжении 220px поверх белого. Лёгкая акцентная заливка сверху помечает колонку как территорию ассистента.

**Шапка колонки:** 48px, отступы `0 10px 0 14px`, нижняя граница line.

**Лента сообщений:** занимает остаток высоты, прокручивается, прокрутка не передаётся наружу. Внутренние отступы `14px 12px 16px`, между сообщениями 12px.

**Сообщение:** максимальная ширина 92% колонки, появление 0.28s основной кривой.
Пузырь: радиус 14px, отступы `9px 12px`, 13px / 1.45.

| Автор | Оформление |
|---|---|
| Пользователь | фон ink, белый текст, правый нижний угол 5px, прижат вправо |
| Ассистент | фон surface, текст text-soft, граница line, левый нижний угол 5px, прижат влево |

Вложения, отправленные с сообщением, показываются под ним и выравниваются по краю пузыря.

**Карточка предложения изменений:** во всю ширину, белая, радиус 14px, граница line-strong, тень md, то же появление. Обработанная карточка — `opacity: .62`.

Чипы диффа: отступы `3px 7px`, радиус 6px, `500 11px/1`, tabular-nums.

| Тип | Фон | Текст |
|---|---|---|
| добавлено | ok-soft | `#15803D` |
| изменено | warn-soft | `#B45309` |
| удалено | danger-soft | `#B91C1C` |

**Индикатор набора:** три точки 5px цветом faint, подскок на 4px, цикл 1.05s, задержки 0 / 0.14s / 0.28s.

**Строка ввода.** Порядок слева направо: поле → кнопка отправки → кнопка вложения. Подсказки клавиши Enter внутри поля нет.

```
контейнер:  flex, выравнивание по нижнему краю, зазор 8px, отступ 10px
поле:       радиус 11px, граница 1px line-strong, белый фон, отступы 8px 10px
            фокус: граница #B9C0FA + кольцо 0 0 0 3px rgba(92,108,245,.12)
текст поля: 400 13px/18px, без ручного ресайза, максимальная высота 108px
отправка:   36×36px, радиус 11px, градиент #6B7BFF → #4A55C9,
            тень 0 4px 12px rgba(92,108,245,.28)
вложение:   36×36px
```

**Все три элемента ровно 36px в высоту.** Расчёт: 18px строка + 16px вертикальных отступов + 2px границ. При изменении размера шрифта в поле высоту строки пересчитать, иначе выравнивание поедет.

Кнопка отправки: наведение — градиент `#7C8AFF → #4450C4` и усиленная тень; нажатие — `scale(.94)`; отключена — `opacity: .28` без тени.

## 8. Панель свойств

Сверху вниз: шапка выделения → секции свойств. Вкладок в панели нет — она всегда показывает свойства текущего выделения.

**Шапка выделения:** отступы `14px 16px 12px`, нижняя граница line. Внутри бейдж типа объекта (отступы `2px 7px`, радиус 999px, фон accent-soft, текст accent-strong, 10px/600/uppercase/трекинг `.08em`), под ним название 14px/600 с обрезкой многоточием.

**Секция:** отступы `14px 16px 16px`, нижняя граница line, заголовок 10px/650 uppercase цветом muted с отступом снизу 12px. Цветных полос-индикаторов у секций нет и быть не должно.

**Строка «подпись — контрол»:** flex с разносом по краям, зазор 12px, минимальная высота 32px, отступ снизу 8px. Подпись слева 12px цветом muted, контрол прижат вправо.

**Поле с лейблом сверху:** лейбл, под ним контрол, отступ снизу 12px.

### Панель выравнивания (9 позиций)

Квадрат 84×84px, радиус 10px, граница line-strong, фон surface, переполнение скрыто.

```
внутренний отступ: 6px
зазор между ячейками: 4px
размер ячейки: (84 − 6·2 − 4·2) / 3 ≈ 21.33px
```

**Скользящий бегунок** — отдельный слой под сеткой ячеек: размер ячейки, радиус 5px, белый фон, тень

```
0 0 0 1px rgba(92,108,245,0.45),
0 2px 6px rgba(46,55,150,0.14),
0 0 14px rgba(92,108,245,0.18)
```

Позиция задаётся смещением `отступ + индекс × (ячейка + зазор)` по обеим осям, переход `transform 280ms` основной кривой и `box-shadow 280ms ease`. Переход включается только после первого отрисованного кадра — иначе при появлении бегунок едет из левого верхнего угла.

**Точка в ячейке:** 8×8px (центральная 10×10px), радиус 2px, цвет `#A1A1AB`; активная — `#4A55C9`, `scale(1.12)`, свечение `0 0 8px rgba(92,108,245,0.35)`; переход 220ms.

Отключённая ячейка (режим «только горизонталь») — `opacity: 0.25` и обычный курсор.

Подпись-пояснение справа от квадрата: 11px / 1.45 цветом subtle.

## 12. Содержимое превью приложения

Объекты внутри макета телефона стилизуются данными самого приложения (позиция, размер, радиус, цвета из его темы), а не токенами этой системы. Цвета интерфейса внутрь экрана не протекают.

Единственное, что система задаёт для содержимого превью, — пресеты движения:

| Пресет | Параметры |
|---|---|
| Парение | 6s бесконечно, `translateY(0 → −7px → 0)` |
| Пульс | 2.6s, прозрачность `1 → .82`, масштаб `1 → 1.04` |
| Дыхание | 3.6s, масштаб `1 → 1.07` |
| Дрейф | 14s, смещение до `10px / −12px`, масштаб `1.06` и `0.97` |
| Появление | 620ms `cubic-bezier(0.16, 1, 0.3, 1)`, снизу вверх на 14px с масштаба 0.98 |
| Блик | 3.2s линейно, сдвиг фона с `200%` до `−60%`; требует `background-size: 220% 100%` |

Элементы с анимацией помечаются как изменяющие трансформ и прозрачность. При включённом снижении движения все пресеты принудительно отключаются.

## 13. Анимация

| Что | Параметры | Назначение |
|---|---|---|
| Появление слоя | 0.18–0.22s основной кривой, `translateY(6px) scale(.98)` → норма | меню, палитры, модальные окна |
| Появление сообщения | 0.28–0.3s основной кривой, `translateY(7px) scale(.985)` → норма | чат |
| Появление панели кода | `translateY(8px)` → норма | панель поднимается с доски, а не падает как модалка |
| Ожидание | 1.05s бесконечно, подскок точек на 4px | индикатор набора |
| Наведение на кнопку | 0.16s ease | фон, граница, цвет, тень, трансформ |
| Наведение на мелкий контрол | 0.14s ease | фон, цвет, граница |
| Перемещение бегунка выравнивания | 280ms основной кривой | панель 9 позиций |
| Смена состояния точки | 220ms ease | цвет и масштаб |
| Фоновые пятна лендинга | 28s / 34s / 40s ease-in-out бесконечно | атмосфера |
| Вращение вуали | 60s линейно бесконечно | атмосфера |

**Основная кривая системы — `cubic-bezier(.22, 1, .36, 1)`:** быстрый старт, мягкое торможение. Применять ко всему, что появляется или перемещается по решению пользователя.

Каждый блок с анимацией обязан иметь ветку для `prefers-reduced-motion: reduce`, отключающую и анимации, и переходы.

## 15. Правила, которые нельзя нарушать

1. Стили интерфейса и стили генерируемого приложения — **два изолированных набора**. Токены и классы одного не используются в другом.
2. В инлайновых стилях не смешивать сокращённые и полные CSS-свойства для одной величины (`padding` вместе с `padding-bottom`) — результат непредсказуем. Только полная форма.
3. Панели меняют ширину колонок сетки, а не накладываются поверх рабочей области.
4. Всплывающие слои внутри колонок с обрезкой переполнения выносятся в отдельный слой над интерфейсом с фиксированным позиционированием.
5. Числовым полям обязательно разрешать сжиматься ниже содержимого, иначе значения обрезаются.
6. Степперы `+`/`−` — только на дискретных величинах. На непрерывных — ползунок и ввод с клавиатуры.
7. Секции панели свойств не маркируются цветом.
8. В макете телефона нет статус-бара.
9. Код цвета выводится тёмным текстом, не серым.
10. Фоновые градиенты доски доводятся до полной прозрачности на 100% размера — видимая граница затухания читается как индикатор загрузки.
11. Любая новая анимация — на основной кривой системы и с обработкой снижения движения.
12. Новый цвет вводится только вместе с новым смыслом и только как токен.
